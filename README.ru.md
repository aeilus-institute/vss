# Инструменты ценности ÆVRI: VET и VSS

Открытые инструменты [Института исследований ценности Aeilus (ÆVRI)](https://aeilus.institute/ru/tools/).

- **VET (Value Estimation Tool).** Разместите список элементов (задачи, идеи, риски) на двух шкалах: что каждый даёт
  (исходящая ценность) и чего стоит (входящая ценность). Список сразу сортируется по приоритету. Бакеты от LOW до BIG,
  антиценность, доска 2D, вставка из таблицы, импорт и экспорт CSV и JSON.
- **VSS (редактор Value System Schema).** Рисуйте, как ценность движется через систему: конвертеры (команды, сервисы,
  подсистемы), потоки ценности и антиценности, типы элементов. Любой поток можно оценить в VET, результат появится
  на потоке. Экспорт в JSON и PNG.

## Запуск

Инструменты - обычные ES-модули без сборки и зависимостей. Браузеры не загружают модули с `file://`, поэтому
откройте папку через любой статический веб-сервер:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080/ . Язык берётся из браузера или из `?lang=ru` (20 языков в `*/assets/locales`).
Данные остаются во вкладке браузера, для сохранения экспортируйте доску или схему.

## Пакеты

| Файл | Что внутри |
| --- | --- |
| `aevri-vet-editor-<v>.zip` | только VET (`vet/`) |
| `aevri-vss-editor-<v>.zip` | только VSS (`vss/`), без кнопок VET |
| `aevri-value-tools-<v>.zip` | VSS и VET вместе и набор для командного режима (`team/`, `contracts/openapi.yaml`) |

## Встраивание

Настройки задаются атрибутами `data-*` контейнера (`data-share="off"`, `data-server="off"`, `data-vet`,
`data-embed="vss"`, для командного режима `data-api`, `data-signin`, `data-board`, `data-schema`). VET встраивается в
вашу систему через iframe `vet/embed.html` и протокол `postMessage` `aevri.vet` версии 1
(`contracts/vet-bridge.schema.json`). Пример кода и таблица атрибутов - в `README.md`.
